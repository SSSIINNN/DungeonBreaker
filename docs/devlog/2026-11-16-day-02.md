# 던전깨기 개발 일지 — 2일차 (2026-11-16)

던전 클리어 후 출구를 쉽게 찾고, 전투 중에는 타격 여부와 남은 체력을 바로 알 수 있도록 개선했다.

| 항목 | 2일차 구현 보고 | Studio에서 확인할 동작 |
| --- | --- | --- |
| 출구 방향 표시 | 클리어 후 바닥에 출구 방향 화살표 추가 | 전투 중에는 숨겨져 있고, 마지막 몬스터 처치 후 열린 출구를 가리킨다. 다음 방 이동·재도전·로비 복귀 시 이전 화살표가 남지 않는다. |
| 타격과 피격 표시 | 피해 숫자와 피격 효과 추가 | 실제 피해가 적용된 경우에만 피해 숫자가 나오고, 공격 적중과 플레이어 피격을 화면에서 구분할 수 있다. |
| 체력 UI | 플레이어와 몬스터의 체력 표시 개선 | 공격·피격 시 체력이 갱신되고, 재도전 시 체력 표시가 새 상태를 반영한다. |

세 항목의 구현 완료는 2일차 대화에서 보고됐다. 당시 변경분이 포함된 커밋과 각 항목의 Studio 테스트 결과는 확인하지 못했다. 이 문서를 추가하기 전의 [프로토타입 커밋](https://github.com/SSSIINNN/DungeonBreaker/commit/13aff2c9cfa4ac4b7e570393d810a3e206fba4eb)에서는 클리어 후 출구 개방, 서버의 피해 처리, 기본 체력 표시를 확인했다.

다음 검증은 최신 로컬 소스를 Rojo로 Studio에 연결한 뒤, 입장 → 전투 → 클리어 → 출구 통과 순서로 진행한다. 이후 재도전과 로비 복귀에서 UI와 화살표가 정리되는지 확인한다.
